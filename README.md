# Stocks

This is a personal project with the purpose of normalising stock data across multiple brokers into a unified frontend portfolio viewer.

It is not, and probably never will be a production ready application. It just does what I need it to do, which is:
- Connect to the IBKR and SAXO brokerage API's
- Transform stock listings, positions, transactions and account balances into a common data format
- Attaches geograpic data to each listing
- Normalises all currencies into my base currency at the current exchange rate
- Calculate forex profit / loss seperately from unrealised profit / loss
- Present a combined portfolio in a GUI frontend
